点击下方按钮即可下载当前 FTC Open Library 项目源码。压缩包不含 node_modules、.next 和 .git。

ftc-open-library-source.zip

大小
约 648 KB（不含 node_modules）
内容
App Router 源码、组件、文档、Supabase 迁移与种子数据
不含
依赖安装目录、构建缓存、Git 历史、本压缩包自身
下载 ZIP
  1. 解压压缩包。
  2. 在目录中运行 npm install。
  3. 复制 .env.example 为 .env.local（可稍后填写）。
  4. 运行 npm run dev，打开 http://localhost:3000。

用浏览器直接打开本文件时，下载链接指向同目录下的 downloads/ftc-open-library-source.zip。开发服务器中也可访问 /download.html 或 /download。更新源码后运行 npm run pack:source 可重新生成压缩包。
